# Getting Started

Get your Metis hardware installed and your SDK environment verified.

1. **[Hardware Installation](hardware-install.md)** — physically install your Metis board and confirm the device is detected
2. **[Verify Your Setup](verify-setup.md)** — confirm hardware, drivers, and SDK are all working

---

For software installation and first steps, see [User Guides](../user-guides/README.md).
Windows users: start with [Windows Setup](../user-guides/windows-setup.md) before hardware installation.

**Prerequisites:** Ubuntu 22.04+ (bare metal or WSL2), an available PCIe x4 or M.2 slot, and sudo access.
