# User Guides

Practical guides for installing, configuring, and operating the Voyager SDK and Metis hardware.

| Guide | What it covers |
|-------|---------------|
| [Install the SDK](sdk-install.md) | Clone the repository, run the installer, activate the environment. |
| [First Inference](first-inference.md) | Run a model on your hardware for the first time. |
| [Windows Setup](windows-setup.md) | WSL2 setup, Windows driver installation (including Metis PCIe 4-AIPU / Switchtec), and native Windows inference. |
| [Firmware Update](firmware-update.md) | Update or recover Metis device firmware. |
| [Host Hardware Acceleration with OpenCL and VA-API](hw-acceleration.md) | Configuring host hardware acceleration for preprocessing. |
| [AxMonitor](axmonitor.md) | Monitor device temperatures, utilization, power, and FPS in real time. |
| [LLM Inference](llm.md) | Run Small Language Models on the Metis AIPU using the `axllm` command. |
| [Thermal Management](thermal.md) | Temperature monitoring, throttling thresholds, and safety limits. |
