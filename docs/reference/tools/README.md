# Tools

Command-line tools included with the Voyager SDK. Use these to run inference, compile and deploy models, benchmark hardware, and manage devices.

| Tool | What it does |
|------|-------------|
| [install.sh](install-sh.md) | SDK installer. Sets up the Python virtual environment and downloads model dependencies. Run this first. |
| [axdevice](axdevice.md) | List connected Metis devices, show firmware versions, and manage device configuration. |
| [inference.py](inference-py.md) | Run any model on Metis hardware. The primary everyday tool for inference, display, and benchmarking. |
| [deploy.py](deploy-py.md) | Compile and deploy a model from a YAML definition. Used for custom weights and new architectures. |
| [axrunmodel](axrunmodel.md) | Run a compiled model directly against the AIPU to measure peak hardware throughput. Advanced benchmarking. |
